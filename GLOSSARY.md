# Love Gallery

A private gallery of the times the Curator and the Partner have spent together. They live in different cities, so each Memory is a meeting.

## Memories

**Memory**:
One meeting of the couple: its Media, the Cities it took place in, its Date range and its Occasions. It may have a title and a note.
_Avoid_: Album, trip, visit, gallery (for a single Memory)

**City**:
A place where a Memory happened. A Memory usually has one, but can have several when the couple moved between cities during the meeting.
_Avoid_: Location, place

**Date range**:
The first and last day of a Memory. A one-day meeting has the same start and end day.
_Avoid_: Period, dates

**Media**:
The photos and videos of a Memory. A single photo or video is a Media item.
_Avoid_: Assets, files, attachments

**Layout**:
The Curator's arrangement of a Memory's Media on a grid, setting each item's position and size.
_Avoid_: Masonry, collage, order

**Timeline**:
The gallery's home page: every Memory in sequence as a vertical chain of cards linked by lines.
_Avoid_: Feed, list, home

## Occasions

**Occasion**:
An important day that falls within a Memory's Date range. A Memory may have none or several.
_Avoid_: Event, special day, holiday

**Yearly occasion**:
An Occasion that repeats on the same day every year, such as an anniversary, a birthday or Valentine's Day. It belongs to every Memory whose Date range includes that day.
_Avoid_: Recurring event, predefined date

**One-off occasion**:
An Occasion that exists only on the Memory where the Curator added it.
_Avoid_: Custom event, ad-hoc date

**Theme**:
A small visual style that an Occasion carries, such as its colours and decorations. A Memory takes the Theme of its Main occasion.
_Avoid_: Skin, template, style

**Main occasion**:
The Occasion whose Theme a Memory takes, when the Memory has several.
_Avoid_: Primary event, featured occasion

## Access

**Curator**:
The member of the couple who adds and edits Memories and configures the gallery.
_Avoid_: Admin, owner, user

**Partner**:
The other member of the couple. She has the same access but only looks at the gallery.
_Avoid_: Viewer, guest, user

**Gallery password**:
The single password that opens the whole gallery, Admin page included.
_Avoid_: Login, passphrase, PIN

**Admin page**:
The part of the gallery where the Curator manages Memories, their Layouts and the Yearly occasions.
_Avoid_: Dashboard, backoffice, CMS, admin panel
